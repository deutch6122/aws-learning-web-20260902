利用上のポイント

  • 対象範囲は西新井駅から半径20km、作成するコースは最大25kmです。
  • 経路はOpenStreetMapベースの徒歩向けOSRMルートを使います。私有地、通行止め、夜間閉鎖、階段、混雑などは現地状況を優先してください。
  • 現在地のリアルタイム判定はブラウザの位置情報APIを使います。公開環境ではHTTPS化が必要です。
  • 標高は国土地理院DEMを優先し、取得できない場合はOpen-MeteoのCopernicus DEM GLO-90標高APIへ切り替えます。
  • 外部APIの公開エンドポイントは学習・試作用です。継続運用する場合は利用規約、制限、商用利用条件を確認し、必要に応じて契約APIへ置き換えてください。
